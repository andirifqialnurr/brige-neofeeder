# Bridge Neo Feeder Frontend

React + Vite dashboard untuk Bridge Neo Feeder.

## Stack

- React
- Vite
- TypeScript

## Setup

```bash
bun install
bun run dev
```

Copy `.env.example` menjadi `.env` dan sesuaikan API URL.

```text
VITE_API_BASE_URL=http://localhost:2000/api
```

## Scope Awal

- Dashboard status koneksi.
- Upload dan validasi template Excel.
- Preview dry-run.
- Monitoring sync batch.
- Mapping workspace untuk Phase 2.
